Técnicas del voleibol

Selecciona una técnica para conocer su función.

🏐 1. Saque

Inicia la jugada enviando el balón al campo contrario. Requiere coordinación, control y dirección.

🤲 2. Recepción

Permite controlar el balón que llega del rival y dirigirlo hacia una zona adecuada para continuar la jugada.

👏 3. Pase

También llamado voleo. Ayuda a mantener el balón controlado y preparar la siguiente acción.

🎯 4. Armado

Organiza la ofensiva y coloca el balón en una posición favorable para realizar el ataque.

🔥 5. Ataque

Busca enviar el balón al campo contrario con precisión y aprovechar los espacios disponibles.

🛡️ 6. Bloqueo y defensa

El bloqueo dificulta el ataque rival y la defensa permite recuperar balones y mantener la jugada.

Estrategias de juego

Recursos para comprender mejor la organización del equipo.

⚡ Ataque

Combinar recepción, armado y ataque para aprovechar espacios del equipo contrario.

🛡️ Defensa

🔄 Rotación

Organizar las posiciones del equipo mediante el sistema de rotación.

🤝 Comunicación

Coordinarse durante cada jugada para evitar confusiones.

Reglas básicas

Conceptos básicos para acompañar el aprendizaje técnico.

1. Equipo:
El voleibol se juega con dos equipos separados por una red.
2. Toques:
Un equipo dispone de hasta tres contactos para devolver el balón al campo contrario.
3. Rotación:
Los jugadores rotan cuando recuperan el derecho a sacar.
4. Red:
Los jugadores deben respetar las reglas relacionadas con la red durante las acciones de juego.
5. Puntuación:
Los puntos se consiguen cuando el balón cae dentro del campo rival o cuando el contrario comete una infracción.
